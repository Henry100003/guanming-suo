# 觀命所 · Guanming Institute

AI 命理平台原型：紫微斗數、西洋占星、塔羅牌陣、AI 姓名學四項服務,支援繁中 / 简中 / English / 日本語。純靜態網站(HTML + CSS + JS),無需建置步驟。

| 頁面 | 檔案 |
|---|---|
| 首頁 / 星圖校準台 | `index.html` |
| 登入 / 註冊 | `auth.html` |
| 命盤報告(免費版 / 付費版) | `report.html` |
| App 介面展示 | `app.html` |

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可。

## 說明

- 本專案為產品原型示範,登入、付款、資料儲存皆為前端模擬,不會實際送出或儲存任何資料。
- 命理內容由固定樣板依生辰組合而成,僅供娛樂與自我探索參考,不能取代醫療、心理、法律或財務專業建議。
- 報告頁的「繼續追問」在 Claude Artifact 環境中會呼叫 Claude 產生回覆;在一般網站環境下會自動退回內建的示範回覆。
